05 / Une expérience ciblée

À essayer : un modèle de risque de crédit reproductible

Un jeu de données synthétiques. Un objectif clair. Trois requêtes ciblées.

01
RECHERCHE / ASK
Examiner ces données synthétiques et ce notebook. Repérer les fuites et comparer les découpages de validation. Ne modifier aucun fichier pour le moment.
02
PLAN / HVE RPI
Planifier un modèle reproductible avec un découpage temporel. Ajuster le prétraitement sur les données d’entraînement seulement. Définir les métriques et les tests avant de coder.
03
IMPLÉMENTATION / AGENT
Implémenter le plan approuvé et exécuter les tests. Rapporter la PR-AUC, la calibration et les résultats par sous-groupe. Montrer les changements et les limites restantes.

Critères de réussite

  • L’exécution à neuf fonctionne.
  • Les tests de découpage et de fuite réussissent.
  • Les limites sont documentées.
  • Une personne révise le résultat.

Plus rapide. Aussi rigoureux.

Cadre bancaire : données synthétiques ou dépersonnalisées approuvées seulement; aucun renseignement personnel de client ni secret dans les requêtes.

Notes de présentation et sources

Il s’agit d’un exemple éducatif, pas d’une approbation de modèle de crédit en production. Convenir des seuils avec le métier avant de coder. Tenir compte de l’horizon de prédiction, de l’isolation des clients et des intervalles temporels selon les données. Conserver un jeu de test final intact.

La PR-AUC n’est pas un critère suffisant. La calibration, l’incertitude et les sous-groupes doivent être interprétés dans leur contexte. Une analyse par sous-groupe ne démontre ni l’équité ni la conformité. Une exécution à neuf nécessite des dépendances et des graines aléatoires documentées, ainsi qu’un environnement vierge.

Les politiques du client déterminent les données, les fournisseurs, les autorisations et les durées de conservation acceptables. La dépersonnalisation exige une approbation et ne garantit pas la confidentialité. Les niveaux de capacité proposés sont des conseils d’atelier, pas des exigences HVE. Le comportement et la disponibilité d’Hydrafusion n’ont pas été vérifiés dans la documentation publique de Copilot.
